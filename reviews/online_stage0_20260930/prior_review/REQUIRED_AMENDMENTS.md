## C. 可以保留，不必修改

- 研究问题的比较性表述；理论只作动机，并给出反例（01 §3.2–3.4）。
- 先做 T3A（输出空间），再做 T3B；分析期每个族只跑一个冻结配置；真值辅助诊断只在诊断子集上做。
- 释放时钟 cutoff(t)=t；可用时刻的定义（残差为 s+ℓ，梯度为 s+4）；事件顺序“释放 → 更新 → 保护门 → 发布 → 评分”；actor 与 scorer 同进程，靠 API 边界加投毒测试隔离。
- QC 使用训练时的 mean/std；QC 拆成 actor 与 scorer 两侧；共同评分掩码。
- 各期划分：估计期、隔离带、选择期、预热期、分析期（在补充 A5 的语义之后）。
- 按等响应分族校准；倍数网格 {0.5, 1, 2}；所有候选的分数都保存。
- 指标口径：先池化 MSE 再开方，以 F0 为分母，百分点差值；按周保存充分统计量；三态结论。
- 最小来源清单与 run_id 只写一次；冻结文件清单；STOP 条件（包括“结果反常地好时先排查泄漏，但不预设就是泄漏”）。
- T5 中的 sliding_refit 与 fs_star 基线，以及“单因素变体不超过 6 个”的限制。
