# EarthDelta follow-up plan package

`EarthDelta_Codex_Followup_Plan_20260925.zip` is the canonical archive for the
v6 follow-up plan. The archive is a planning and evidence package; its embedded
authorization state reflects the time it was produced and is not a certificate
that later GPU jobs ran successfully.

The current execution status is recorded in
`EXECUTION_STATUS_20260925.md`, with a compact ACP receipt index in
`GPU_RECHECK_EVIDENCE_20260925.md`. The independent ChatGPT Pro review prompt is
`CHATGPT_PRO_AUDIT_PROMPT_20260925.md`. Runtime receipts, model weights,
datasets, and large GPU artifacts remain outside Git under the AFS run
directories.
