# EarthDelta：以研究价值为中心的 novelty 复核与方案升级

日期：2026-09-22 UTC。代码基准：`d749a1c62521226df857587e08f7d067b0f15355` 及当前未提交工作区。本次任务是研究评估与计划制定；Round 4 的工程结论沿用[实际审计报告](../../codex_audit_round4/ROUND4_REPORT.md)。文献检索截止本日，来源、版本和实际阅读范围见 [LITERATURE_MAP.md](LITERATURE_MAP.md) 与 [literature_review.json](literature_review.json)。

## 1. 我的判断与明确建议

**EarthDelta 值得继续做一个有边界的真实实验。最有希望的贡献，是让昂贵的模型编辑响应能够被复用，并转化为可靠、成本可控的天气适配决策。** 没有必要要求 LoRA、响应预测、路由、残差订正这些组成部分从未出现过。我们需要证明这个组合带来了强基线不容易以同等代价获得的能力。

当前 idea 有清楚的问题意识，也有可复用的数学和代码基础；目前还缺少支撑方法价值的完整天气实验。四专家、固定幅度、固定目标下的路由收益，可以验证可行性，但很难单独支撑较强的研究主张。建议把研究重心推进到：**同一个响应模型，在预报目标和编辑动作改变后，还能否以少量额外校准继续做出有效选择？**

这不是推倒重写。旧版 [EARTHDELTA_V2.md](../../codex_audit_round2/context/round1/research/EARTHDELTA_V2.md) 已经明确提出 `e/du` 分解、动作描述符、多时效和无在线候选 rollout。本轮真正建议增加的是三件事：

1. 把“能复用”写成明确的动作/目标留出实验，并计量重新仿真、标注、训练和部署的总代价。
2. 学习足够支撑决策的误差信息，减少对整个高维天气误差场的无效预测；用同信息的直接收益头检验这种结构是否值得。
3. 主线通过后，用共同探针得到的行为描述补充专家 ID，研究新专家或新时效上的低成本接入。

可以采用工作标题 **EarthDelta: Reusable Intervention-Response Models for Goal-Conditioned Weather Adaptation**。这是研究目标，不是已经得到实验支持的论文结论。

| 判断对象 | 当前结论 | 什么会提升判断 |
| --- | --- | --- |
| 问题价值 | 明确：大型天气模型下游适配、长程副作用、候选仿真成本都真实存在 | 在相同信息与计算预算下给出可复现的实际收益 |
| 组成部分 novelty | 多数已有先例，可直接引用和借鉴 | 不需要把每个组件重新包装成原创 |
| 方法组合的潜力 | 有条件值得推进，尤其是响应复用与决策表示 | 联合动作/目标迁移、校准成本曲线、真实执行收益 |
| 当前科学证据 | 尚不足以证明优于强路由或反馈订正 | 合格共同 Fs/专家库、完整候选缓存、时间隔离的策略比较 |
| 当前工程产物 | 尚不能放行正式 Stage 4 | 关闭 Round 4 的前置阻断项，见执行计划 |

## 2. 从近期 CV/NLP 工作中实际借鉴什么

这些工作提供方法和实验设计的启发。表中描述的是论文提出的机制；本文没有复现它们的性能。近期来源多数为预印本，其发布时间与结果成熟度需要分别看待。

| 论文与领域 | 值得借鉴的具体内容 | EarthDelta 的落地方式 | 不直接照搬的部分 |
| --- | --- | --- | --- |
| [DART](https://arxiv.org/abs/2609.20051v1)，2026-09，视频扩散 | 相同 LoRA 在新生成日程下的功能可能改变；用配对前向响应做目标日程校准 | 编辑幅度、hold 或预报时效变化后，测少量实际响应，再判断是否能复用旧预测器 | 不直接搬运其视频模型权重坐标变换；天气长程响应不满足其局部近似的保证 |
| [L-State](https://arxiv.org/abs/2609.08618v1)，2026-09，语言模型训练响应 | 从同一 checkpoint 分支做标准化微干预；比较自由读出与结构化算子读出 | 所有专家共享同一 Fs；统一行为探针；同时比较结构头和普通回归头，按真正的决策收益选择 | 原文干预是短程训练，EarthDelta 是固定权重编辑后的天气 rollout，任务并不相同 |
| [W2T](https://arxiv.org/abs/2603.15990v1)，2026-03，LoRA 表征 | adapter 权重本身包含行为信息；须处理 LoRA 因子分解的不唯一性 | 先用 `DeltaW * Z = scale * B * (A * Z)`、范数、block/window 等便宜描述，再比较行为探针 | 四专家不足以支撑一个大型权重编码器的泛化训练；暂不引入完整 Transformer 编码器 |
| [LiST](https://arxiv.org/abs/2608.22370v2)，2026-08，语言/视觉语言 | 联合参数与行为描述、局部候选、接受/回退规则 | 新专家接入时用行为相似性；所有方法共用 no-edit 与经验性退化控制 | 其在线 CMA-ES 和多次随机前向很贵，不能把它直接接入后还声称零候选 rollout |
| [HyperFix](https://arxiv.org/abs/2608.11499v1)，2026-08，视觉模型合并 | 用少量低阶组合学习组合残差，测试更大的组合 | 先量测两专家的真实非加性；只有它影响选择时才增加交互响应分支 | 权重空间 Gram 不是天气输出交互；其局部条件不自动适用于 72h rollout |
| [Proxy Policy Steering](https://arxiv.org/abs/2609.09148v3)，2026-09，视觉机器人 | 匹配参考代理与任务代理，用差分减少共同近似误差，并逐步修正轨迹 | 加入强反馈订正器、共享编码器的差分蒸馏和 virtual-edit 对照 | 不能直接把 flow-matching 速度场公式套到 Stormer；差分误差抵消也需要实测 |

另有几个特别影响研究定位的近邻：

- [WeatherPEFT v2](https://arxiv.org/abs/2509.22020v2) 已涉及天气基础模型任务适配；[TaCT](https://arxiv.org/abs/2603.19325v1) 涉及概念条件化的天气编辑。我们的价值应通过状态、时效与编辑结果的关系体现，不能只靠“天气 + 条件 LoRA”。
- [VI-MoLE](https://arxiv.org/abs/2608.02528v1) 已讨论激活 LoRA 前的风险/价值估计；因此“先预测收益再决定执行”本身不是足够强的独占主张。
- [CCM](https://arxiv.org/abs/2605.14546v1) 的共同 anchor 和 PDE 专家坐标有借鉴价值；[CLAW](https://arxiv.org/abs/2609.12278v1) 则提示直接条件化 hypernetwork 应作为后续挑战者，而不是自动给 EarthDelta 再添一个模块。
- [Sampling Headroom Is Not Selection Gain](https://arxiv.org/abs/2609.13257v1) 强调 oracle 空间和合法选择器收益之间的缺口。这个实验纪律值得采用，但它本身也不是本项目的新发现。

文献带来的积极启示是：**干预结果可以成为一种可学习、可迁移的对象。** EarthDelta 可以把这个方向落实到有真实真值、多个预报时效和明确运行代价的天气系统。不同领域之间的借鉴完全合理；需要独立证明的是天气场景下带来的能力与代价。

## 3. 原有设计中最值得保留的部分

定义共同冻结参考 `Fs`，实际动作预报 `Fa`，未来真值 `Y`：

```text
e = Y - Fs
u(a) = Fa - Fs
L_Q(Y,F) = (Y-F)^T Q (Y-F)
g_Q(a) = L_Q(Y,Fs) - L_Q(Y,Fa)
       = 2 e^T Q u(a) - u(a)^T Q u(a)
```

`Q` 必须是当前合同中的有效权重，已经包含尺度和一次性归一化。新 `full_objective_*` 实现经 Round 4 的独立手算验证。这个恒等式是标准代数；它的价值在于分离了两种学习对象：天气真值相关的误差，以及可通过模型仿真获取的编辑响应。

保留以下设计：共同 Fs、有限动作集、明确 no-edit、离线实际配对响应、合法输入信息、选中后真实运行、全时效副作用检查，以及 `gain_analytic`/`gain_calibrated` 的分离。

当前可复用代码：`earthdelta/heads.py:106` 与 `:140` 的分头接口；`:262` 的多时效组合头；`earthdelta/geometry.py:10` 的局部响应几何；`earthdelta/metrics_contract.py:557` 的 Q_eff 路径。旧 head 的默认校准和旧 reducer 接线仍需修复，不能因接口已存在就视为科学流程已完成。

值得收窄的说法：

- 精确恒等式加预测的 `e/u`，得到的是预测收益，不是精确真实收益。
- 若把 `u(a)` 近似为 `R a`，`R^T Q R` 是线性响应的重叠；它不等于真实非线性动作交互。
- LoRA rank=4 不意味着未来天气响应空间也只有四维。
- 参数编辑能否比反馈输出订正更稳或更省，须通过实验判断；两者都可能改变后续轨迹。
- 不需要未来真值就能采集 `u`，仍然要支付仿真成本。ERA5 标签相对丰富，不宜把“标签稀缺”当作唯一主要动机。

## 4. 推荐升级：一条主线、一个后续扩展

### 4.1 主线：复用有限动作响应，学习决策所需的信息

对外研究问题是：**在相同历史信息和离线预算下，分解式响应模型是否比直接收益预测，更容易复用于新动作和新目标？** 这应成为最先回答的科学问题。

最小实现分三层：

1. `I_t`：合法历史、日历/静态量、已声明的冻结特征；若使用 reference preview，所有比较方法都能使用，且计入完整成本。
2. `a`：专家、幅度、作用 block、hold、continuation、lead 的明确描述；首轮使用真实有限动作响应，避免未经验证的线性外推。
3. 分别预测参考误差信息与动作响应，按冻结目标打分；根据开发侧校准的规则选择动作或 no-edit；执行选中动作并保留决策日志。

**关键改进是减少误差头的无关预测负担。** 对固定 `Q` 和候选响应集合，只有 `Q^(1/2)e` 在这些响应张成空间上的投影会影响候选排序。这是普通线性代数提供的设计依据，不需要包装成新定理。

一种可实现的压缩版本：从训练侧响应学习共同物理场基 `V`，用 `u(a) ≈ V z(a)` 表示响应。对预先注册的目标分量 `Q_m`，预测：

```text
c_m(I) ≈ V^T Q_m e
z(I,a) ≈ response coordinates
M_m = V^T Q_m V
g_hat_m(I,a) = 2 c_hat_m(I)^T z_hat(I,a)
               - z_hat(I,a)^T M_m z_hat(I,a)
```

当真实 `u` 完全落在 `V` 的列空间，且 `c/z` 已知时，公式精确；截断基和预测头会产生误差，必须在原生目标上评价。基只在 policy-fit/训练数据上拟合。先比较少数维度和低容量读出，别先建高容量天气编码器。

这使我们可以比较：原始完整 `e/u`、只预测决策分量的结构头、直接标量/向量收益头。保留全场或足够细的响应缓存，以便做原生 loss、区域目标和物理诊断；不能只存压缩分数后宣称任意目标可复用。

### 4.2 必须设置的强对照：向量收益头

设每个 `Q_m` 已独立定义并正确归一化，`w_m >= 0`、`sum(w)=1`：

```text
Q(w) = sum_m w_m Q_m
g_Q(w)(a) = sum_m w_m g_Qm(a)
```

直接预测 `[g_Q1, ..., g_QM]` 的向量收益头，也能不重新训练就适应新权重。**仅在新目标权重上胜过“只预测旧目标一个标量”的弱基线，不足以证明响应分解有价值。** 若把原始 q 混合后再归一化，要把实际等效权重同样交给基线。

因此主实验要进一步留出动作幅度/作用窗口，测试目标和动作共同变化时的效果；或者展示相同精度下更少的新增仿真/再训练成本。向量收益头获得相同动作描述、行为探针、模拟数据和调参预算。

基 `V` 对一种目标有效，不保证覆盖另一种区域或变量目标。完全新 `Q` 超出训练目标族时，要单列需要的标签、响应场分辨率和校准工作，不能把任意零样本迁移写进主张。

### 4.3 后续扩展：给专家一个可比较的行为描述

K=4 先用于验证训练、缓存与选择。主线有信号后，再增加以下动作描述：

```text
d_a = [coefficient, block/window/lead, update norms,
       fixed weight sketches, fixed probe-response summaries]
```

权重 sketch 首选 `scale * B * (A * Z)`，其中 `Z` 对各专家固定；它依赖实际 `DeltaW`，对等价 LoRA 因子重参数化不敏感。简单比较原始 A/B 距离会受分解方式影响。W2T 的 QR/SVD 方案可作后续实现参考，但符号和重复奇异值约定也需处理。

行为探针从 bank-fit 侧预先冻结的小面板取样；所有专家从相同 Fs、相同初态运行，记录分变量、空间和时效的响应，不只记录一个响应范数。它们无需未来天气真值，但确实需要前向计算。新专家只允许在这个固定校准面板上运行若干次，不在待评估起报上逐候选探测后仍声称无候选 rollout。

建议检验“0/2/4/8 个校准起报”的接入曲线，与同预算直接收益方法、从头重训方法比较。四个专家不足以证明新库泛化；若此扩展值得做，先扩到三个独立训练的 K=4 库作开发，按整个库留出，再用新库和未使用时间段确认。所有这些库仍需共享相同 Fs；换 backbone/Fs 是另一个更难的问题，暂不混入。

### 4.4 模块增加规则

| 观察到的瓶颈 | 下一步 | 暂不增加 |
| --- | --- | --- |
| 全场误差难预测，相关投影可预测 | 决策分量读出，比较排序/原生收益 | 大型 JEPA/记忆模块 |
| 新幅度/窗口失败，但探针能解释变化 | 行为描述与小样本校准 | 每个测试起报的在线搜索 |
| 两专家实际响应明显非加性且导致错选 | 小型交互响应残差，有限幅度内验证 | 任意大组合、全 Jacobian |
| oracle 好、合法选择器不行 | 误差/响应四格诊断，改善合法状态特征 | 直接扩成更大的专家库 |
| virtual edit 或反馈订正更好 | 将主张转向响应蒸馏/动态订正 | 为保留参数编辑形式继续堆模块 |

如确需交互分支，先量测 `u(a_i+a_j)-u(a_i)-u(a_j)`。这个残差是真实输出非加性；现有 Gram 的交叉项不是它。首轮不默认增加。

## 5. 最有区分力的实验设计

### 5.1 先证明“存在可用的选择空间”

在合格共同 Fs 上，从 `no-edit + 4 个单专家动作` 开始。每个起报完整运行全部候选，记录 6h/24h/72h 目标、失败、成本和身份。

比较 Fs、训练/开发侧预选的最佳固定候选、合法 cheap router、oracle。oracle 必须相对同一候选集的最佳固定方案报告余量；无编辑必须在表内。不能只报告相对 F0 的提高，因为静态适配本身就可能贡献这部分收益。

若当前字典几乎总是同一专家最好，先做一次有预算的字典改良：按不同训练侧目标/时效权重或天气 regime 训练专家，再检查实际响应是否互补。数据量、更新预算和资格门要匹配；不得用 confirm 收益选专家。没有必要为月份分组硬赋予物理语义。

### 5.2 核心模型比较

| 方法 | 必须公平匹配的内容 | 回答的问题 |
| --- | --- | --- |
| Fs / 最佳固定候选 | 同 bank、目标与数据身份 | 动态决策是否必要 |
| regime/ridge/小 MLP direct-gain | 同合法信息、候选、标签及模拟数据 | 能否用更便宜的方法完成选择 |
| descriptor-conditioned vector-gain | 同动作/目标描述及行为探针 | 目标复用是否只是普通多输出回归 |
| 原版 e/u 头 | 同编码器和调参预算，raw/calibrated 分报 | 分解本身的价值 |
| 决策分量 + 响应头 | 同上，增加基截断误差报告 | 表示是否更高效、更易泛化 |
| 直接 edited-forecast 蒸馏 | 相同模拟轨迹与上下文 | 分解是否优于直接学习候选输出 |
| virtual edit：`Fs + u_hat(a_selected)` | 同选择器；另计生成完整 Fs 的成本 | 是否需要执行真实参数编辑 |
| 逐步 feedback corrector | 同真值、历史、更新可用时间与成本账本 | 参数编辑能否提供额外天气价值 |

小容量 direct-gain 先跑；神经网络比较等待足够 policy-fit 样本。128 个起报适合可行性与开发诊断，不能因为有许多格点就当成足够多独立训练案例。

### 5.3 留出矩阵

| 轨道 | 训练/开发可见 | 评价留出 | 合理结论 |
| --- | --- | --- | --- |
| A：固定任务 | K=4、a0=0.25、24h 主目标 | 后续时间块 | 基本选择是否有效 |
| B：目标重组 | 预注册分量目标、部分权重组合 | 新的权重组合 | 目标复用；必须比较向量收益头 |
| C：动作变化 | 训练幅度/hold 的一部分 | 范围内的未见幅度或作用窗口 | 同库动作迁移；不要一次改变全部因素 |
| D：联合迁移 | A/B/C 的开发组合 | 未见动作与未见目标的联合组合 | 更有说服力的复用能力 |
| E：新专家，条件扩展 | 多个开发库，固定探针预算 | 整个新库及独立时间段 | 有限校准的新专家接入能力 |

例如幅度 `{0.125,0.25,0.375}` 可作初始设计，但必须先满足系数合同与训练侧响应资格；若现有半径不允许，不为实验方便放宽。首轮只做留一幅度；hold 迁移在第二步做。留出的响应不得用于训练基、归一化、调参或“无标签”响应预训练。评价它们需要的离线真实 rollout 记在评估成本，不输入选择器。

### 5.4 学习误差与收益之间的区别

除均方误差和相关性，还报告实际选中动作的收益、相对最优动作的 regret、退化频率、退化尾部与 no-edit 比例。预测 `u` 很准，但误差方向错了，仍会选错动作。

可用四格诊断定位瓶颈：`(true e,true u)`、`(pred e,true u)`、`(true e,pred u)`、`(pred e,pred u)`。前三格是离线诊断，不是可部署方法；不能混入合法策略榜。

若 `I` 是压缩或不完整的上下文，条件均值直接代入二次式还可能遗漏：

```text
E[g | I] = 2 mu_e^T Q mu_u - mu_u^T Q mu_u
           + 2 tr(Q Cov(u,e | I)) - tr(Q Var(u | I))
```

当动作响应在给定完整 `I` 后确定时，上述 u 方差/协方差项消失。这里不是断言现有系统必有该偏差，而是说明校准应作为独立消融；应比较 raw geometry、加性校准和直接收益，避免用校准掩盖分解是否有效。

### 5.5 什么结果足以构成贡献

以下任一方向得到公平、重复的证据，都值得发展：

- 在联合目标/动作迁移中，原生天气收益和长程退化控制优于同信息的直接收益模型。
- 相同效果下，新任务/新专家所需的额外模拟、再训练或校准成本显著降低。
- 相似平均效果下，长时效副作用更小、失败处理更可靠，且部署开销有明确界限。

胜过很弱的固定路由、只有 oracle 提高、仅 latent MSE 下降、只在筛出的成功起报上有收益，都不属于这类证据。具体优效/等效阈值在开发阶段确定并在 confirm 前冻结，不在看到测试结果后解释“多小的提升也算成功”。

## 6. 当前代码和数据如何影响推进顺序

Round 4 已确认：formal Fs 出现真实优化退化、四进程分别拟合了不同 Fs、动态专家权重未序列化、profiling 会更新已验收权重、准入与 registry 的实际身份消费仍有缺口。这些缺陷会使响应标签本身失去共同参照。**先修最小数据生产链，是为了尽快得到能回答研究问题的实验。** 不要求先完成一个通用平台。

必须先关闭 C01-C06/C09；C07/C08 在新 head 比较前修复；C11 在扩展幅度候选前修复；当前独立进程/串行调用下，不必把 C10 扩大成并发框架建设。官方 S0 仍为 BLOCKED，正式等价性结论需恢复实际官方验证。

当前 2015/2018/2019/2020 的 Zarr 元数据有全年 shape，2016/2017 为零时间步，2021 未见完成的最终 store。shape 不是内容认证。可行的初始角色是：2015/2018 做 bank-fit，2019 做 policy-fit，2020 作为已经暴露的 development/calibration；具体需要核查旧使用账本、backbone 训练截止时间和实际 UTC 端点。2020 曾用于 Fs/debug，不能称 untouched confirm。确认集使用后来完成并未被使用的时间段。

各划分按真实时间及历史/目标支持范围隔离；在分界处至少排除会跨界使用历史或未来端点的起报。统计按天气时间块重采样，块长覆盖 rollout 重叠与开发集估计的相关性，不能把格点或相邻 6h 起报当独立样本。

## 7. 推进与转向规则

**建议次序：可信最小管线 → 小库完整缓存与 cheap baseline → 决策分量/完整响应/向量收益比较 → 联合迁移 → 条件性新库扩展。** 具体 10 小时启动窗口及后续多日安排见 [EXECUTION_PLAN.md](EXECUTION_PLAN.md)。

| 实验事实 | 决策 |
| --- | --- |
| 字典有余量，cheap legal 也能实现部分收益 | PASS 到结构模型比较；不用再扩展文献审计 |
| oracle 几乎无余量 | PIVOT 一次专家目标/数据设计；仍无余量则 STOP 当前字典路线 |
| oracle 有余量，所有合法模型都无收益 | 检查输入信息与误差可预测性；限定一次改良预算，别无限加专家 |
| direct/vector-gain 与结构头相当且更便宜 | 收窄主张为实用动态适配，或转向响应模型的复用任务；不强推结构优势 |
| virtual edit/feedback 更优 | 保留响应学习，转向动态订正或响应蒸馏，形成真实有用的结果 |
| 响应结构在联合迁移或校准成本上胜出 | 扩大独立样本、种子和库，再做未触碰时间段的确认 |
| Fs 或身份/持久化资格失败 | FAIL_IMPLEMENTATION / BLOCKED；不据此否定科学 idea，也不放行正式缓存 |

本次推荐没有把“完全不重叠”作为目标。应争取的是一组可解释、可复现、代价清楚的实证结果，使读者愿意在自己的天气模型上采用这个方法。
