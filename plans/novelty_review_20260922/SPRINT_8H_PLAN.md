## 1. 八小时要回答三个具体问题

1. **可行性：** 从同一冻结天气模型出发，低秩专家能否产生可复现、有用的预报改变，并由合法输入驱动选择？
2. **方法价值：** 相同数据、动作描述和计算预算下，误差/响应分解能否胜过强直接收益预测，或用更少的训练起报达到相似效果？
3. **复用能力：** 训练未见的编辑幅度与目标组合同时出现时，响应模型还能否选出有效动作？

八小时的最高目标是取得支持上述问题的真实 pilot 证据，包括负结果。文献新颖性通过已有相关工作定位，方法贡献通过对照实验支持；不能预先保证八小时得到正结果，也不能用一次 pilot 宣布跨专家库或跨 backbone 普遍泛化。

## 2. 首轮采用明确的缩小合同：共同参考 R = F0

**本轮主实验固定 `reference_kind=base_frozen`，即 R 等于原始冻结 checkpoint F0。** 先不把静态 Fs 拟合放在主流程上；它作为独立诊断任务运行，不改变已经冻结的主实验参考。

原因是 Round 4 已确认 formal Fs 退化，四 worker 还各自拟合了不同 Fs。若把八小时首先押在全部静态拟合根因上，可能没有时间检验研究假设。`R=F0` 保留了“共同参考 + 动态专家 + 响应预测 + 选择”这一核心机制，同时避开静态训练本身的混杂。

这是新的、有明确范围的 pilot，不是给旧 Stage 3b/Stage 4 放行。旧 Fs 问题继续保留原审计状态。报告相对 R 和最佳固定动态专家的收益；不能把 R 的结果写成“优于经过良好静态适配的 Fs”。若主线有信号，下一轮再将同一设计复验于合格 Fs。

仍然必须满足以下前提：

- 实际输入/目标的 UTC 时间、norm/grid/channel/content 绑定通过；旧 admission 记录不得未经复核复用。
- 官方/实际执行栈的 S0 覆盖所用 rollout，或将执行栈差异独立报告。官方 S0 未通过时，允许做标明实现范围的工程诊断，正式可行性资格仍为 BLOCKED。
- 所有动态专家加载同一个 R；权重真实落盘、独立进程重载验证；profiling 不得改变验收后的参数。
- 真实前置失败不执行后继；正式 registry 绑定 R、动态 checkpoint、Q 和动作身份。
- 所有评分使用新 full-objective 合同；analytic 与 calibrated 分报；选择直接携带候选 ID，避开近似系数反查。

复用现有原语完成一条最小可验证路径即可。现有 `--stage all` 会重新拟合 Fs，**本轮不得原样复用** `bank_train_formal_4experts_argv.json`；需要新增显式 base-reference 路径和共同 reference manifest。

### 4.2 专家与动作

K=4、每专家 rank=4、blocks 18–23、6h 步长、hold=4 步后回到 R，训练目标为 24h。保持已有分组设计，不在本轮同时更改专家结构、记忆、JEPA 或 RL。

动态专家训练初始 LR=1e-3、clip=1、最多 300 updates；在 32/128/300 更新保存训练侧固定面板。LR 是预先选择的待验证设置，不保证收敛。四个不同固定 seed 对应四专家，所有专家共用 R；若失稳，最多一次预先定义的 LR=3e-4、128-update 重试，且不能侵占缓存和收尾截止。

checkpoint 选择仅看本专家训练侧资格面板的 24h 均值，同时报告各样本、6/24/72h 退化。默认资格要求：24h 均值不超过同面板 R 的 1.001 倍、72h 均值不超过 1.05 倍、全部有限且响应非零，并通过保存重载。每专家资格面板至少 8 个起报。0.1%/5% 是本轮预注册的工程准入阈值，不是已经由应用需求证明的最优阈值；实际策略还要通过更严格的 72h guard。不得按 2020 表现选专家。资格字段缺失则不发布。

当前 `DEFAULT_RHO=0.25`。动作集合采用：

```text
训练/校准可见：no-edit，以及每专家的 alpha = 0.125、0.25，共 9 个动作。
封存评价增加：每专家的 alpha = 0.1875，共 13 个动作。
主迁移比较的可选集合：no-edit + 四个 alpha=0.1875 的动作，共 5 个。
```

三个幅度均在现有半径内，保持单专家 support。训练 bank 仍用 0.25，新增幅度只是缓存/决策动作；不能把 BankTrainConfig 的训练 a0/rho 合同偷偷放宽。新 registry 逐行核验实际系数且携带稳定 ID。

制定计划时已在 CPU 上实际构造全部 13 行，通过当前 EditPlan/registry 的系数、回读和 hold 窗口检查，见 [动作兼容性记录](evidence/sprint8h_action_compatibility.json)。这只验证动作表示兼容；正式产物身份绑定与天气执行仍是待完成工作。

0.1875 的响应不能进入 response basis、辅助训练、校准或超参数选择。即使不需要未来真值，使用该响应训练也会破坏“未见动作”实验。完整 13 动作只用于 debug 与封存评估。

### 4.3 目标

三分量分别为原生 6h、24h、72h 加权目标，使用相同注册变量尺度/面积权重；每个分量内部正确归一化。已见目标主比较使用 24h。联合迁移目标固定为：

```text
Q_joint = 0.2 Q_6h + 0.5 Q_24h + 0.3 Q_72h
```

这是“新幅度插值 + 新目标权重组合”的有限范围测试，不是跨库或任意新目标泛化。向量收益基线同样知道目标权重，可以直接重新加权；单纯目标重组不计为独立 novelty 证据。所有方法另报 72h 单独损失，避免混合均值掩盖后期损害。

## 5. 最小方法矩阵：保证强对照先完成

所有方法共享合法输入 I：当前分析态、可用的真实历史差分、日历量；使用相同池化/编码器。首轮不依赖完整 reference preview 提取特征。若确需 preview，所有方法获得相同内容并计其成本。未来 truth、真实候选输出与 oracle 分数不能进入选择器。

| 优先级 | 方法 | 具体实现/作用 |
| --- | --- | --- |
| 必做 B0 | R、校准侧最佳固定专家、oracle | 分清静态收益、动态余量与合法可实现收益；oracle 仅离线 |
| 必做 B1 | 直接向量收益：ridge/小 MLP | 输入含 expert ID、alpha、alpha² 与状态交互；输出三个 native gain，目标改变时重新加权 |
| 必做 E1 | e/u 分解头 | 同编码器；预测参考误差与有限动作响应；raw gain 为主，加性校准为单独 variant |
| 优先 E2 | 决策分量头 | 训练侧响应基 V，预测 `V^T Q_m e` 和响应坐标；检验比完整误差预测更易学习与否 |
| 必做诊断 | true/pred e × true/pred u | 区分响应、误差与选择瓶颈；有真值的格子不能列作部署方法 |
| 条件扩展 B2 | virtual edit、直接候选输出蒸馏 | 检验需要真实参数编辑还是代理输出已足够；不宣称已替代完整反馈订正对照 |

B1 至少包含强二次幅度特征，避免用只能线性外推收益的弱基线衬托二次评分。同信息下比较 ridge 与小 MLP，由 calibration 选择并在揭示 holdout 前冻结；不得用 holdout 挑一个较弱直接基线作主对手。

头部尽量使用小 MLP/闭式回归，先不训练新的大编码器。每种神经方法至多 4 组超参数、固定 3 seeds；共同早停规则，主比较每个 seed 单列，再汇总。学习曲线用预先固定的嵌套 64/128/256 个 policy-fit 起报，所有方法获得相同的对应模拟信息；每档的响应基、特征变换与学习到的缩放也只在该档数据上拟合，不能以 256 个起报学好 basis 再称“只需 64 个”。未完成 E2 时，E1/B1 的比较仍有效，但不能宣称决策分量改进得到支持。

若完整天气场输出太重，采用同一个训练侧冻结的空间摘要/低秩表示；basis 只在 fit 数据上学习。其分数是近似分数，必须报告原生响应重构误差，并用真实执行的 native loss 判优。表示丢失过多时标记表示瓶颈，不把失败推广为整个 idea 不可行。不要在八小时内新建通用全场 SVD 平台。

逐步 feedback corrector、多库泛化、跨 backbone、极端天气专项和 learned critic 留给下一轮。因此八小时可以提供贡献候选的证据，不能声称已经优于所有合理替代方案。

## 6. GPU 资源安排与吞吐决策

默认使用两个可排队的 4×H100 任务组，共最多 8 张卡同时做有用工作。若完整 cache 已就绪且吞吐确有需要，可增加至四个四卡 cache 任务；不假设节点必定立即可用，不以空等任务预占卡。

| 任务 | 建议资源 | 就绪条件 |
| --- | --- | --- |
| J0：真实环境/S0 | 一个四卡节点按需使用；无需为占满而重复验证 | 完整脚本/配置准备好，参考和消费按依赖执行 |
| J1：动态专家 | 4 卡独立进程，各一个专家、同一 R | G0 PASS；实际执行身份匹配 |
| J-Fs：可选失稳对照 | 另一节点，至多 4 卡、30 分钟 worker 预算 | 不阻塞主实验；同初始状态对照 1e-2 两次、1e-3、3e-4 |
| J2：cache | 4–8 卡，必要时更多已就绪分片 | G1/G2 PASS；每起报全部对应动作一起处理 |
| J3/J4：head/评价 | 通常 4 卡已足够；ridge/统计可 CPU | cache 全部覆盖、split/holdout 访问合同通过 |

一进程一个模型，不共享 hook 的线程，不为这个 pilot 新引入 DDP。AFS 可能成为瓶颈；GPU 利用率低且读写饱和时，不盲目加节点。5090 只在其实际环境/显存已验证，或 H100 路径不可用时采用；切换需记录执行栈并重新验证相应资格。

标准预算的 cache：`(256+64)*9 + 128*13 + 8*13 = 4648` 条轨迹；每条最长 12 步，共 55,776 步。只存 6/24/72h、69×128×256 FP32 预报端点约 126.11 GB（117.45 GiB），另加 truth、特征、manifest 和临时量；准备至少 200 GiB 的可用空间并监控实际写入。

T+2:45 按 8 起报实测做 ETA：以“每起报完整对应候选集合”的 wall time、卡数、I/O 实测缩放，加 30% 缓冲。只按 ETA 选择：

- 标准：256 fit / 64 calibration / 128 holdout，4648 条轨迹。
- 缩小：128 / 32 / 64，2376 条轨迹，约 64.47 GB 端点；仍保留幅度留出和强基线。
- 若缩小预算也不能在 T+4:30 前完成：只完成可信 debug 与可行性记录，`novelty_signal=INCONCLUSIVE`。

标准/缩小样本列表均提前生成，缩小时取固定嵌套子集，不能取先成功或收益好的子集。历史 490 秒 formal 作业仅用于说明已有训练路径可运行，不作为本轮缓存时长的保证。

## 9. 统计与证据判定

主比较提前固定为：**联合目标 Q_joint 下，alpha=0.1875 的五动作集合，E1 对 calibration 预选的 B1；另报相对 R 与 calibration 预选固定专家。** E2 是预先声明的次比较。若 E2 未实现，不用其他事后结果顶替主比较。

calibration 对未见幅度没有真实收益标签。其固定专家必须根据已见幅度的预定汇总规则选择，并将该专家应用于 0.1875。holdout 上事后最佳固定专家可以另列描述性上界，不能冒充可部署的预选固定基线。

报告 native loss/gain、regret、no-edit 率、72h 均值与尾部退化、失败率，以及完整离线/在线成本。聚合多 seed 时先对同一起报取均值，再按完整时间块计算配对区间，同时展示各 seed；不能把 3×128 当成 384 个独立天气样本。

默认用固定 UTC 14 天块做配对 bootstrap，7/28 天仅作预先声明的敏感性分析。样本不足或区间宽时保留 INCONCLUSIVE。2020 已暴露及本轮单 bank 的限制必须伴随结论；这些区间是 pilot 证据，不是最终项目确认。

| 字段 | PASS / 初步支持条件 | 不足时如何报告 |
| --- | --- | --- |
| `pipeline_feasibility` | 真实资格、重载、完整缓存、选中动作重放通过 | BLOCKED 或 FAIL_IMPLEMENTATION，附具体记录 |
| `weather_utility` | 合法策略相对 R/预选固定的真实增益支持正向；长程损害在冻结容差内 | 正负点估计、CI、退化表；不能只报 oracle |
| `novelty_signal` | weather_utility 通过；主比较对强 B1 的增益除以同批 R 平均 loss 后，其 95% 下界 > 0.001，至少 2/3 seeds 同向，72h guard 通过 | INCONCLUSIVE；若数据明确反对则 NOT_SUPPORTED |
| `data_efficiency_signal` | 预定义嵌套学习曲线支持较少起报达到冻结等效带内效果，且计入所有模拟信息 | 只报曲线，不用它事后替换未通过的主比较 |
| `full_fs_pipeline` | 本轮不以此为主实验完成条件 | 原审计问题仍 OPEN；可选诊断单独报告 |

具体预注册默认值：主方法增益门槛为 R 平均 loss 的 0.1%；72h guard 要求 `(mean L_method72 - mean L_R72) / mean L_R72` 的 95% 上界不超过 0.5%；样本效率比较固定 E1@128 对 B1@256，允许劣化的等效带为 R 平均主目标 loss 的 0.1%，同时满足 guard。区间按块重采样后重算比值。它们是本轮工程决策尺度，不承诺业务价值或统计功效；可在 T+0:20、未运行方法前有理由地修改一次并冻结，不能看 holdout 后放宽。缺字段不得判 PASS。

样本效率报告同时列出各方法所需模拟信息与本次实际共享缓存总成本；已有全量 cache 上的子集曲线不能被描述为“本次实际已经节省了一半 GPU”。不得以放宽训练数值容差替代天气质量改善。

## 10. 八小时交付包

运行目录至少包含：`source_manifest.json`、`frozen_spec.json`、reference/bank/registry manifest、动态 checkpoint、S0/准入/重载证据、cache 覆盖表、冻结预测、完整方法 CSV、成本账本、作业状态，以及 `RESULTS.md` 与 `decision.json`。
