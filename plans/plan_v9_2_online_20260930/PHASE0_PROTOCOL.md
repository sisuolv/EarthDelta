## 2. 因果及拟合产物的可用性

线上回放顺序固定为释放→更新→保护门（仅T5）→发布→评分。残差的标签到达label_available为 s+ℓ，四步反馈包和梯度为 s+4；usable_after还必须取与其依赖的冻结产物可用时刻的最大值。worker 的提前计算不让 actor 提前获取记录。衰减年龄使用原始label_available，不使用artifact完成或文件生成时间，否则估计结束时批量生成的历史梯度会被错误视为同样新鲜。

拟合期校准是**离线拟合**，可使用完整估计期的均值/分母，不能把其历史日期上的结果称为当时可部署的预报。它使用单独offline_fit入口：artifact上下文为估计期结束，原始反馈仍要求label_available≤该校准日期t；不能伪造早于02-29的artifact时间来调用在线release(t)，不能用当期真值构造 lag1。估计期模型最晚依赖02-29真值，因而03-01选择期前可用。

最终输出重拟合最晚依赖03-31真值。不能用这份模型在03-27“发布”预热期适配预报；只在分析启动时用已兑现 F0 记录重建状态，再于04-01开始有效发布。所有拟合 artifact 记录 source_roles、max_valid/available、生成时刻和版本；`Derived` 不允许省略这些依赖。

## 3. 信息公平性

设 `B_s` 为同一F0起报的六变量×步骤1,2,3,4反馈包，包括原始监督ID、输入ID、F0/损失/分母版本。包在 s+4 后且四步全部 QC 合格时才释放。

| 臂 | 在 t 使用的记录 |
|---|---|
| F0 | 当前合法输入；无监督 |
| OBC | 拟合冻结偏差 |
| DABC | 本时效全部已兑现残差，按 label_available 的日历年龄衰减 |
| OCL-fresh | 目标时效的已兑现历史 + **恰好 t−1日** 的完整 B_s；包含 lag1/lag1c 用到的所有原始标签和可访问历史输入 |
| lag1/lag1c | 恰好 t−1日 B_s 导出的梯度；lag1c 再减冻结估计均值 |
| ewma_g | 全部已释放 B_s 的原始梯度，按日历EWMA |
| delay30 | 恰好 t−30日的梯度，减去与lag1c相同的冻结均值后单位化；不能改取最近有效日期 |
| static | 冻结估计期原始梯度均值 |

OCL-fresh 的标签 lineage 必须包含参数主臂的标签 lineage；不比较 residual_record_id 与 gradient_record_id 的字面字符串来冒充信息一致。不同表示/雅可比是算法差异，不能声称表达能力已对齐。缺包时 OCL-fresh 与 lag1(c) 均回退F0；缺同目标时效历史时 OCL-fresh 也回退，不用零填补。

## 4. 指标、损失与拟合选择

6变量索引：Z500=11、T850=53、T2m=0、MSLP=3、U850=27、Q700=65；评价步1/4/12/20；主格 Z500/T850×24/72h。面积权重在完整H×W归一化；先池化MSE再开方。所有 I 以F0作分母，I_a−I_b单位为百分点。

梯度损失为六变量×前四步的平均 `physical_MSE / D_est_short`；选择损失为六变量×四个评价步的平均 `physical_MSE / D_est`。D 是估计期F0的正确池化MSE，即 RMSE 的平方，不能拿 RMSE 本身除 MSE。两套分母只在估计期计算、校验正有限并冻结，禁止搬旧probe分母或用差分std替代状态误差定义。

原始梯度以FP32保存，FP64累计均值和范数；`g_mean_est = mean(raw_g_s)`，`lag1c=-unit(raw_g_{t−1}-g_mean_est)`。原始尺度先中心化、后单位化；不平均单位梯度。mean不在全拟合期重算，以保持幅度校准身份。

OCL-fresh 使用每个反馈变量/步的EOF（共24个短反馈块）以及目标时效EWMA特征；均值、EOF、特征尺度和Ridge只在估计目标行上拟合。K∈{10,20}、正则λ∈{.001,.01,.1,1,10}；sklearn `alpha=n_train*λ`，对应平均平方损失正则。目标时效EWMA特征固定τ=7天，不再搜索。缺行按显式因果条件排除，不嵌套 RidgeCV/TimeSeriesSplit。

候选数：OBC2、DABC8、OCL-fresh10、lag1c3、lag1 3、static3、ewma_g12、delay30 3。ewma_g的τ与DABC一致（3/7/15/30天），每个τ单独等响应校准、再选3个倍数。这些选择预算并不相等，完整披露，不写“全方法相同调参预算”。

等响应按第4步**全部69个状态标准化通道**的能量比，逐issue计算后取16例中位数，目标0.1。梯度损失与效应比是不同对象。a/||W_target||的预设括区为[1e-6,1e-1]，12次对数二分，加两个端点最多14次评估；容差5%，已采样中位响应的单调性绝对容忍1e-4。零分母、超过该容忍的非单调、未括住或超容差均为技术BLOCKED，不按分析结果改括区。

零方向的响应按0进入原16例中位数，不删样本。若某候选全部16例方向均为0，预定冻结成F0等价族（a=0,m=1），不是“校准已达0.1”；后续得分照常包含它。部分零方向仍走同一校准门，不能挑非零例重新校准。

| 规则 | 预先固定的通过标准 |
