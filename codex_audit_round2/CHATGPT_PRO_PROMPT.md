## 核心 idea

固定参考天气模型 F_ref 和一组参数编辑候选 a。在签发时刻只使用当时合法可用的信息 I，学习：

- 参考误差 e0 = truth - reference 的预测；
- 候选编辑响应 du(a) = edited forecast - reference forecast 的预测；
- 在同一输出空间与固定 Q 下，以 `gain(a) = 2 e0^T Q du(a) - du(a)^T Q du(a)` 组合收益，再在成本/稀疏/幅度/窗口预算内选择编辑，允许 no-edit。

若响应能写为 `du(a)=R a`，系数目标为 `2 b^T a - a^T H a`，其中 `b=R^T Q e0`、`H=R^T Q R`，非对角项用于处理候选响应的重叠。实际有限候选也可以直接计算完整非线性响应，无须假设 singleton 可叠加。

研究希望借助“du 可从模型仿真获得、e0 需要核验标签”的分解，获得标签效率、动作泛化、跨预算/目标复用或成本上的优势。这些优势尚未通过天气实验验证。
